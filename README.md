What this project is about

The project compares a weak AI prompt with a strong one, using the same task: a university lecturer asking AI to help build lecture slides on supply and demand for an intro economics class.

It shows:
A bad prompt ("Make me slides about economics") and why it fails, since it leaves out the role, student level, length, and context the AI needs.
A strong prompt that fills in those gaps, explained using the RACE framework: Role, Action, Context, Expectation.
A short follow-up prompt that fixes a weak spot in the first draft, showing that AI output usually needs one round of refinement before it's ready to use.
A final check against five criteria: task suitability, prompt quality, refinement, privacy, and verification.
Main point

The quality of an AI prompt decides the quality of the result. Giving the AI a role, a clear task, real context (like where students got confused before), and a clear format turns a generic answer into something a lecturer can actually use in class.
